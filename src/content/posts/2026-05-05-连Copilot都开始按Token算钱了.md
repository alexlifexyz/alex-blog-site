这两天我看到两个消息连在一起，心里一下子紧了。

一个是 `2026-04-27`，GitHub 官方宣布，`Copilot` 从 `2026-06-01` 起要从按请求数，转成按用量计费。

说白了，就是开始认真按 `token` 算钱了。

另一个是 `2026-05-04`，豆包在 App Store 页面上出现了测试中的付费版本，价格直接拉出了三档：

- `68 元 / 月`
- `200 元 / 月`
- `500 元 / 月`

豆包后面回应说，免费服务继续有，付费方案还在测试。

但这个回应其实已经够用了。

因为真正值得注意的，不是某一家到底今天收不收费。

而是一个更大的信号：

`AI 便宜时代，可能真的快结束了。`

以前很多人用 AI，用的是一种“包月幻觉”。

每个月花一笔不算太高的钱，然后默认自己可以把各种脏活累活、写作、查资料、改代码、搭工作流，全都塞进去。

你会慢慢产生一种感觉：

这玩意儿虽然厉害，但反正套餐摆在那里，多用一点也无所谓。

现在平台开始把这层幻觉一点点收回去。

为什么？

因为 AI 已经不太像一个普通互联网会员了。

它越来越像云资源。

你买的不只是“能不能用”。

你买的是：

- 模型算力
- 响应速度
- 高峰时段的排队权
- 长上下文和多轮推理的消耗权

以前平台愿意补贴，是因为要抢用户、抢场景、抢心智。

现在很多重度用户，已经真的把 AI 接进工作流里了。

一旦你开始拿它写代码、做分析、跑复杂任务，平台迟早会把真实成本往回传。

所以这波变化，我觉得重点根本不是“Token 变贵了”。

重点是：

`免费和低价，正在从生产力工具里慢慢退场。`

以后免费版当然还会在。

但它更像入口层、体验层、轻使用层。

真正想把 AI 当工作搭子的人，后面越来越像是在买一份算力服务。

而且最难受的，还不只是贵。

是你开始没法像以前那样，轻松预估自己的成本。

一个月 `20` 美元，你能接受。
一个月 `68` 元，你也能接受。

可如果变成：

- 这个月到底会不会烧到 `80` 美元
- 哪一步最费
- 为什么同样一个任务，这次比上次贵这么多

这种不确定，才是最烦的。

GitHub 这次连预估账单和预算控制都一起推出来，其实已经说明他们自己也知道，真正让人焦虑的不是单价本身，而是失控感。

还有一个很多人容易忽略的点。

以后用 AI，最贵的可能还不是 `token` 本身。

而是你围着它多出来的那些隐性成本。

比如：

- 你为了省钱，来回切模型，结果上下文重喂了三遍
- 你觉得长上下文省事，最后一次任务塞得太满，反而烧得更快
- 你把 Agent 放进流程里，多跑了几轮，看上去高级，实际上返工更多
- 结果不稳，你还得重新核、重新改、重新补

最后你账单也花了，时间也赔了，注意力也散了。

所以以后真正该看的，不会只是“哪家最强”“哪家最便宜”。

而是：

`完成一件真实任务，到底总成本是多少。`

这里面的总成本，至少包括四样：

- 订阅费
- token 消耗
- 切换和返工时间
- 结果不稳带来的额外损耗

我现在越来越觉得，后面 AI 会把人分成两层。

一层是轻度用户。

查点东西、问点问题、偶尔写写东西，这批人会一直有免费版或者低价版可用。

另一层是重度生产用户。

真的拿它写代码、做分析、接进业务、接进日常工作流的人，月成本慢慢走到 `100` 美元、`200` 美元，并不奇怪。

这不是危言耸听。

`ChatGPT Pro` 现在就是 `$200 / 月`。
`Claude Max` 也已经有 `$100 / 月` 和 `$200 / 月` 两档。

这说明平台已经在公开告诉你：

高强度使用 frontier model，本来就不是一个便宜爱好。

所以如果今天你问我，普通开发者后面该怎么办。

我会先说三件事。

第一，不要默认所有任务都值得交给最贵的模型。

把值钱的判断、关键的结构、风险高的步骤，交给更稳的模型。

重复活、低风险活、能自己兜住的活，尽量放到便宜层。

第二，不要只盯单次价格，要盯整条工作流的总成本。

便宜模型如果让你返工三次，就不便宜了。

第三，越到后面，越要学会做预算感。

你不一定要天天记 token。

但你至少得知道：

- 哪些动作最烧钱
- 哪些模型是你的主力
- 哪些高强度需求不值得每天开

以前大家总说，AI 会越来越强，越来越便宜，最后像水电一样。

现在看，至少对真正高强度使用的人来说，事情没那么简单。

它会越来越强，这没问题。

但它未必会继续便宜到可以让你毫无感觉地一直开着用。

所以这波变化，我觉得不是坏消息。

它更像一个提醒：

`以后会用 AI，不只是会提问。`

还包括你会不会控成本，会不会配工作流，会不会分清什么值得交给模型，什么不值得。

平台开始认真算钱了。

我们也该开始认真算账了。
