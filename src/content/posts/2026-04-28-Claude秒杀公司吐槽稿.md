Anthropic 又翻车了：封公司、降智、乱扣钱，简直在替 OpenAI 拉新

先说结论。

Anthropic 这几天的表现，已经不是“产品偶尔抽风”了。

这是连环翻车。
而且每一波都精准踩在用户最怕的地方。

你以为你买的是世界级 AI 工具。
结果用着用着，体验越来越像一个脾气古怪、随时断电、出账单还特别积极的外包系统。

最离谱的一波，是最近社区里疯传的“整家公司一起被 Claude 抬走”。

有公司员工一早收到邮件，说账号因为违反使用政策被暂停。
大家一开始还以为是谁自己手滑翻车了。
结果去 Slack 一对，发现不是一个人，是一群人一起没了。

更魔幻的是，申诉入口还是 Google Form。

对，Google Form。
不是企业后台，不是专属支持，不是客户成功经理。
是 Google Form。

你都做成企业级 AI 公司了，出了组织级事故，第一反应还是给客户甩个表单。
这画风真的很像：
“您好，系统把你全家封了，麻烦填一下问卷，我们有空看。”

更气人的不是被封。
是你根本不知道为什么被封。

有人猜是不是聊天里提到了农业、肥料这些词，被安全系统误判了。
到底是不是，外面没人说得准。
Anthropic 也没给出什么像样解释。

这就很要命。

企业最怕的从来不是规则严。
企业怕的是你既严，又不说人话，还一刀切。

今天能因为你不知道的原因把一家公司集体踢出去，明天就能在你最忙的时候再来一次。
这种东西不叫“安全感”，这叫“抽奖”。

结果封禁这事还没吐完，Claude Code 那边又来了一刀。

最近一段时间，用户一直在骂 Claude Code 变傻了。
不是那种玄学层面的“我感觉它不如以前懂我”。
是很具体的那种：
推理变浅了，代码味儿变糙了，回答越来越短，很多该做的判断也不做了。

大家骂了很久，Anthropic 前面那段时间基本属于能不正面说就不正面说。
直到 4 月 23 日，官方才发工程复盘，承认确实是自己这边连上了三个问题。

一个是默认 reasoning effort 从 `high` 改到了 `medium`。
一个是会话里旧 thinking 的清理逻辑出了 bug，搞得 Claude 越干越健忘。
还有一个，是他们后来又塞了一条限制 verbosity 的 system prompt，结果把编码质量一起压下去了。

翻成人话就是：
用户骂了半天“你家模型是不是变笨了”，官方后来的意思差不多是：模型未必自己变了，但我们在产品层一通操作，确实把它折腾笨了。

这事最妙的地方就在这。

你明明是来买“更强的 Claude”。
结果收到的是“经过产品团队精心调教后，智商打了折的 Claude”。

真有一种去健身房办了年卡，结果教练趁你睡觉把器械都卸了一半，第二天再安慰你：
不是你变弱了，是我们帮你重新平衡了体验。

还没完。

这两天另一个槽点也很炸。

有用户爆料，自己的 Git 提交历史里只是出现了 `HERMES.md` 这个字符串，Claude Code 就疑似被路由到额外 usage 计费，订阅没先吃掉，账单先飞起来了。

一天下来，多扣两百刀。

最黑色幽默的是，用户去找支持，前面先撞上一套标准化客服话术，后面虽然据说承认是 bug，但最开始还不愿意退。

这个剧情放在别的行业里，已经很接近喜剧了。

你正常订着月费。
你正常写着代码。
你 Git 里多一个文件名。
然后系统默默绕开你的订阅，开始用更贵的方式向你收费。

这已经不是“计费有点复杂”了。
这是“钱包也能被 prompt injection”。

把这几件事连起来看，就更有节目效果了。

一边是账号说封就封。
一边是模型说降智就降智。
一边是计费规则还能突然给你整点隐藏剧情。

整个用户体验像什么？
像你在用一台跑得很快的跑车，动力确实猛，但方向盘会随机卡死，油表会偶尔撒谎，车门还可能在高速上自己弹开。

你说它性能强不强？
强。

你说你还敢不敢一家老小全坐进去？
那就是另一回事了。

最搞笑的是，Anthropic 平时又特别爱讲安全、边界、风险、责任。
这些词本身没问题。
问题是你对外讲了半天供应链风险，结果现在越来越多用户开始把你自己当供应链风险。

这就有点讽刺了。

一个公司最容易失去客户的时候，不一定是它最弱的时候。
往往是它明明很强，但又开始让人不敢信的时候。

Claude 现在给人的感觉，已经越来越接近后者。

你可以贵。
你可以限流。
你甚至可以脾气差一点。

但你不能一边让用户深度接入，一边把可预测性做成盲盒。

因为企业和重度用户最怕的，从来不是“今天不好用”。
是“我不知道它明天会怎么不好用”。

所以最近全网那句提醒，真不是废话：
别把核心工作流只押在 Claude 一家。

能多路由就多路由。
能备份就备份。
能提前演练替代方案，就别等事故当天再临时找药。

不然哪天你正开会、正发版、正赶 deadline，结果全公司 Claude 一起阵亡。
那个场面，已经不是焦虑了。
那是喜剧片突然转灾难片。

至于 OpenAI、Gemini、Groq，还有一堆开源模型，现在估计都在旁边默默鼓掌。

真的，不用他们自己打广告。
Anthropic 这几波操作，已经在帮同行做用户教育了。

我只想替广大用户问一句：

你们的安全系统、限制系统、扣费系统都这么有想法了。
能不能顺手也把“别把正常用户气笑”这件事，一起纳入系统设计？

不然再这么搞下去，Claude 以后最稳定的能力，可能不是写代码。
是给全网稳定生产吐槽素材。
